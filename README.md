# Kaprekar's Routine

An interactive web page that shows how any 4-digit number reaches **6174** (Kaprekar's constant) and any 3-digit number reaches **495**.

1. Sort the digits from largest to smallest.
2. Sort them from smallest to largest.
3. Subtract, then repeat with the result.

## Features

- Type a number, or pick a random one, then run the routine step by step or all at once.
- 4-digit and 3-digit modes.
- A chart of how many steps every starting number needs.
- English and Thai (ไทย) text.

## Run it

Open `index.html` in any browser. It is a single file with no build step.

To publish it with GitHub Pages, go to **Settings → Pages** and choose the branch that holds `index.html`, with the root folder.
